# 国际化与语言边界

## 实现

采用 Zotero 官方支持的 Fluent 语言资源注册。构建从 src/strings.json 生成 locale/en-US/zotero-veil.ftl 与 locale/zh-CN/zotero-veil.ftl。所有语言键均使用 zotero-veil- 前缀。单一文案源避免设置、动态反馈与语言文件分散维护。

bootstrap 使用 Zotero 沙箱提供的 Localization 构造器，建立 Veil 私有上下文，启动时异步预取译文并缓存。没有同步语言IO，也不把Veil资源插入共享document.l10n。UI只对 #zmt-settings 内显式data-veil-text/label节点修改文字与aria-label；只给本插件区域设置lang。设置入口标签通过正式PreferencePanes注册。

读取 Services.locale.appLocaleAsBCP47，不设置requestedLocales、intl.locale.requested或其他语言偏好。中文包括同语言区域回退到简体中文，其他语言使用英文。跟随Zotero重启后的实际语言，不单独控制宿主语言。插件元数据名称和简介使用固定英文，主题设置内容为本地化界面。
