# 隔离测试

先运行自动测试与构建，再准备新的隔离配置：

```sh
npm test
npm run build
python3 scripts/isolated-test.py prepare
```

准备命令输出临时目录，在其中创建profile和空data目录；不会修改日常配置。使用输出路径启动Zotero：

```sh
/Applications/Zotero.app/Contents/MacOS/zotero -no-remote -profile /private/tmp/zmt-test-实际输出/profile
```

测试桥仅接受隔离目录。生产XPI不包含桥，需在该隔离实例中手动安装待测XPI。调用脚本：

```sh
python3 scripts/isolated-test.py call --file tests/live/fixtures.js
python3 scripts/isolated-test.py call --file tests/live/helpers.js
python3 scripts/isolated-test.py call --file tests/live/interaction.js
```

fixtures创建合成测试文献；PDF检查需要独立测试PDF及对应附件。soft-pdf脚本从隔离夹具读取附件ID；请确保已创建对应测试PDF，不应对任意库运行。运行脚本前阅读其前提条件。settings脚本用于打开主题设置。

只在隔离进程已停止时运行reset，避免下次启动重放请求：

```sh
python3 scripts/isolated-test.py reset
```

实体鼠标键盘、VoiceOver和桌面动态材质需要人工验证。合成事件仅说明真实应用处理路径可执行，不代表物理输入检查。
