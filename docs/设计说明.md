# 设计与技术边界

以官方 Material Color Utilities 的 Tonal Spot 配色角色统一深浅色。统一磨砂底层，左右外壳使用 surfaceContainerLowest 的8%色层，普通文字行不独立铺厚底；选择使用 secondaryContainer/onSecondaryContainer，主要动作使用 primary/onPrimary，边界使用 outline，正文使用 onSurface。导航保持方形，保留 Zotero 虚拟表格行高与字体缩放。

通透度0–100线性映射附加色层100–10%。该数值是CSS色层，不代表桌面背景实际透射率；NSVisualEffectView保持全强度，深色使用HUD/DarkAqua，浅色使用HUD/Aqua；这不是原生可变模糊半径。高通透度下无法保证任意背景文字对比度，系统辅助功能优先回退实色。

原生材质仅注入插件拥有的主窗口视图，保存并恢复窗口opaque与backgroundColor。样式、事件、偏好监听和设置页在禁用时清理；保留插件自身偏好。阅读器通过renderToolbar接入，PDF页外仅修改已确认的html/body/viewerContainer背景，不触碰纸张、canvas、文本与标注层。精确URI限制排除笔记等其他文档。

Google官方参考：https://m3.material.io/ ，配色库：https://github.com/material-foundation/material-color-utilities 。本项目适配原生组件，不宣称完整实现Google组件库、ripple或所有自适应断点。应用功能和数据操作继续由Zotero负责。
