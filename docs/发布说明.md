# Zotero Veil v1.0.5

## 更新内容

- 修复打开 PDF 后阅读器样式反复刷新、持续占用 CPU 的问题。
- 避免重复写入未变化的样式，保留主题切换及 PDF 加载时的正常更新。

受影响环境复测：CPU 从持续约 117%–130% 降至空闲时约 1%–2%，雾面玻璃及其他插件保持启用。实际占用会随设备、文献和操作变化；本次未测量 GPU 功耗或电池续航。

外观、功能及已有设置保持不变。

## 安装

下载本次 Release 附件中的 `zotero-veil-1.0.5.xpi`，通过 Zotero **工具 → 插件 → 从文件安装插件** 安装，然后重启 Zotero。

适用于 Apple Silicon macOS 与 Zotero 10。其他平台待测。

---

## What's New

- Fixed a reader stylesheet refresh loop that caused sustained high CPU usage after opening a PDF.
- Avoided rewriting unchanged styles while preserving updates when switching themes or loading PDFs.

In the affected environment, CPU usage dropped from a sustained approximately 117%–130% to around 1%–2% at idle, with frosted glass and other plugins still enabled. Results vary by device, documents, and activity. GPU power consumption and battery life were not measured.

Appearance, features, and existing preferences are unchanged.

## Installation

Download `zotero-veil-1.0.5.xpi` from this release’s assets, install it through Zotero **Tools → Plugins → Install Plugin From File**, then restart Zotero.

For Apple Silicon macOS and Zotero 10. Other platforms remain untested.
