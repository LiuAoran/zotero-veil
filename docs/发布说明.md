# Zotero Veil v1.0.2

## 中文

### 本次更新

- 新增完整的简体中文与英文设置界面，跟随 Zotero 语言；其他语言回退英文。
- 本地化设置入口、配色预设、帮助文字、保存反馈、错误提示和无障碍标签。
- 只翻译 Veil 自己的界面，不修改 Zotero、系统或其他插件的语言。
- 统一采用“雾面玻璃”命名，已有视觉效果、偏好与操作不变。
- 更新双语说明与设置截图。

### 安装

下载附件 `zotero-veil-1.0.2.xpi`，在 Zotero“工具 → 插件 → 从文件安装插件”中安装。设置入口为“Veil 外观”。更改 Zotero 语言后按提示重启。升级保留已有设置。

已在 Apple Silicon macOS / Zotero 10.0.6 验证，其他平台待测试。

## English

### What’s New

- Added complete Simplified Chinese and English settings, following Zotero’s interface language; other languages fall back to English.
- Localized the settings entry, color presets, help text, save feedback, errors, and accessibility labels.
- Translations are limited to Veil. Zotero, system, and other plugin language settings are never changed.
- Standardized the material wording as “Frosted glass” without changing visual behavior, stored preferences, or existing controls.
- Updated bilingual documentation and settings screenshots.

### Installation

Download `zotero-veil-1.0.2.xpi` from this release’s assets and install through Zotero’s **Tools → Plugins → Install Plugin From File**. Open **Veil Appearance** in Settings. Restart Zotero when prompted after changing its interface language. Existing preferences are retained on upgrade.

Tested on Apple Silicon macOS with Zotero 10.0.6. Other platforms remain untested.
