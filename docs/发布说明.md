# Zotero Veil v1.0.1

更通透的玻璃，保留柔和背景模糊。

- 深浅色统一使用 HUD 原生材质，分别保留 DarkAqua 与 Aqua 外观。
- 通透度最高档保留10%附加色层，原生模糊始终保持全强度。
- 保留轻微侧栏色差、选中与焦点状态，以及现有主题设置和文献操作。
- 保留卸载清理修复，禁用后恢复原界面。

已在 Apple Silicon macOS 与 Zotero 10.0.6 验证；其他平台待测试。高通透度下若文字不清，请适当降低数值。

安装 Zotero-Veil 的 XPI 后，打开“设置 → Veil 外观”调整。设置即时生效并自动保存，升级保留已有偏好。
