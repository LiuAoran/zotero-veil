# Zotero Veil v1.0.4

## 更新内容

- 标签筛选区新增胶囊外观，淡底色跟随 Veil 种子色，选中和焦点状态更清晰。
- 保留 Zotero 原生标签尺寸、自动换行及筛选操作，撤回对内部布局方法的适配。
- 处理用户报告的新建子集合卡死问题，受影响环境已确认恢复；具体根因尚未完全定位。
- 调整窗口激活时的主题刷新时序，合并重复刷新，并在禁用时清理等待任务。

深浅色、跟随系统、自定义种子色及雾面玻璃保持可用，升级保留已有设置。

## 安装

下载本次 Release 附件中的 `zotero-veil-1.0.4.xpi`，通过 Zotero **工具 → 插件 → 从文件安装插件** 安装，按提示重启。

主要面向 Apple Silicon macOS 和 Zotero 10。其他平台待测。

---

## What's New

- Added capsule-style tag chips with subtle backgrounds derived from the Veil seed color and clear selection and focus states.
- Retained Zotero’s native tag sizing, wrapping, and filtering; reverted the internal layout adapter.
- Addressed the reported freeze when creating a subcollection. Recovery was confirmed in the affected environment; the exact root cause remains unconfirmed.
- Deferred theme refreshes during window activation, coalesced repeated events, and canceled pending work on disable.

Light, dark, system appearance, custom seed colors, and frosted glass remain available. Existing preferences are retained on upgrade.

## Installation

Download `zotero-veil-1.0.4.xpi` from this release’s assets and install through Zotero **Tools → Plugins → Install Plugin From File**. Restart when prompted.

Primarily intended for Apple Silicon macOS and Zotero 10. Other platforms remain untested.
