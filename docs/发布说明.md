# Zotero Veil 1.0.0

为 Zotero 带来统一配色与柔和磨砂。

- 支持浅色、深色和跟随系统。
- 使用种子色生成配色，提供自定义颜色与三个预设。
- Apple Silicon Mac 原生毛玻璃，可调通透度。
- 统一文献库、详情面板与阅读器外壳，保留 PDF 纸张和标注。
- 设置即时生效并自动保存，禁用后恢复原界面。
- 保留 Zotero 快捷键、文献操作、列宽调整和面板缩放。

适用于 macOS Zotero 10，已在 Apple Silicon Mac 验证；其他平台待测试。

下载 XPI 后，在 Zotero“工具 → 插件”中选择“从文件安装插件”。设置入口为“Veil 外观”。高通透度下若文字不清，请降低数值。
