# Zotero Veil v1.0.3

## 中文

### 更新内容

- 修复添加文献弹窗下方多余的方形背景，保留圆角内容区的实色背景。
- 修复高级搜索输入框与条件行越界；窄面板下自动换行，保持按钮和边框完整。
- 保留中英文界面、主题配色、雾面玻璃及已有设置。

### 安装

下载 `zotero-veil-1.0.3.xpi`，通过 Zotero 的“工具 → 插件 → 从文件安装插件”安装，按提示重启。升级保留已有设置。

## English

### What's New

- Fixed the rectangular backdrop below the identifier lookup popup while keeping its rounded content readable.
- Fixed overflowing advanced-search fields and condition rows; controls wrap within narrow panels.
- Preserved bilingual settings, theme colors, frosted glass, and existing preferences.

### Installation

Download `zotero-veil-1.0.3.xpi` and install through Zotero’s **Tools → Plugins → Install Plugin From File**. Restart when prompted. Existing preferences are retained.

## 验证 / Validation

27 项自动测试及 18 项隔离运行检查已验证本次修复；原生添加弹窗最终系统截图尚未确认。其他平台待测。

The fixes passed 27 automated tests and 18 isolated runtime checks. Final OS-level visual verification of the native lookup popup remains pending. Other platforms are untested.
